# Portfolio - Prabin Thapa

Personal portfolio website showcasing research projects, publications, technical skills, and achievements in Medical Image Analysis and Deep Learning.

## Tech Stack

- React
- Vite
- Framer Motion
- React Icons

## Getting Started

### Prerequisites

- Node.js (v18 or above recommended)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
